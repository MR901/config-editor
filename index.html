New Features & Controls

Manual Sync Control

Edit JSON and YAML independently. Click "Sync →" or "← Sync" to transfer changes between editors.

Independent Formatting

Each editor has its own Format and Compact buttons. Changes only affect that specific pane.

Tree View

Click "Tree View" to see a read-only visual representation of your data structure.

Enhanced Validation

Live validation badges show status. Click Validate for detailed results with line numbers.

Auto-Repair

Click Repair to automatically fix common syntax errors in JSON or YAML.

Toast Notifications

Professional feedback for all operations with clear success/error messages.

How to Use

  • Load Files: Click Load to import JSON or YAML files (auto-detected)
  • Edit Independently: Make changes in JSON or YAML editor without affecting the other
  • Manual Sync: Click sync buttons when you want to transfer changes
  • Format/Compact: Use pane-specific buttons to format or minify content
  • Validate: Check syntax and see detailed validation results
  • Tree View: Visualize structure in a read-only tree (updates when opened)
  • Save: Choose format (JSON/YAML) and save to file

Keyboard Shortcuts

  • Ctrl+Z / Cmd+Z: Undo in active editor
  • Ctrl+Y / Cmd+Shift+Z: Redo in active editor
  • Ctrl+F / Cmd+F: Search in active editor
  • Ctrl+H / Cmd+H: Search and replace in active editor
