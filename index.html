YAML Support

  • Load YAML files: Automatically detected and converted for editing
  • Save as YAML: Export your data in YAML format
  • Dual editor view: See JSON and YAML side-by-side in Code/Text modes
  • Known limitation: YAML comments are not preserved during editing
  • Advanced features: Anchors and multi-line strings are simplified

Keyboard Shortcuts

  • Ctrl+Z / Cmd+Z: Undo last action
  • Ctrl+Y / Cmd+Shift+Z: Redo action
  • Ctrl+F / Cmd+F: Search in document
  • Ctrl+H / Cmd+H: Search and replace
  • Ctrl+D / Cmd+D: Duplicate field or value
  • Ctrl+Enter / Cmd+Enter: Open link or color picker
  • Alt+End: Move to last field
  • Ctrl+M / Cmd+M: Show actions menu

Tips

  • Use Tree mode for visual editing with drag & drop
  • Use Code/Text mode to see both JSON and YAML simultaneously
  • Switch formats anytime using the JSON/YAML toggle
  • The editor auto-detects format when loading files
  • Validation works seamlessly for both formats

⚠️ YAML Format Limitations

Please note the following limitations when working with YAML:

  • Comments are not preserved during editing
  • Anchors and aliases are expanded to their values
  • Multi-line string formatting may be simplified
  • Multiple documents in one file are not supported

The editor is best suited for structural editing. Use Tree mode for the best experience.
