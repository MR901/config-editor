Edit, validate, format, and transform JSON with ease

📚 Features & Keyboard Shortcuts

Editing Modes Tree view, Code editor, and Text mode available via the mode selector
JSON Schema Validation Automatic validation with visual error indicators (define schema in options)
Color Picker Click on hex color values to open the built-in color picker
Search & Replace Ctrl+F (or Cmd+F) to search, Ctrl+H for search & replace
Undo / Redo Ctrl+Z to undo, Ctrl+Y or Ctrl+Shift+Z to redo
Repair JSON Automatically fix common JSON syntax errors with one click

⌨️ Additional Shortcuts

  • Ctrl+D: Duplicate field or value
  • Ctrl+Enter: Open link or color picker
  • Alt+End: Move to last field
  • Ctrl+M: Show actions menu
  • Drag & Drop: Reorder items in tree view
